# R1tec — متجرك الرقمي / Your digital store

Static bilingual (Arabic default / English) storefront for **R1tec**: our Android TV apps first
(R1tec Launcher, R1TV Player), then the digital products from [@r1tec.store](https://www.instagram.com/r1tec.store/).
Every product opens a WhatsApp chat with a prefilled order message.

## Edit
- WhatsApp number & links: `config.js`
- Products / apps / texts: `app.js`
- Product images: `assets/products/`

## Publish on GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
